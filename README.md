# Vue3 Starter Extension Pack

A collection of extensions to get started developing with Vue 3 in Visual Studio Code.

## Extensions Included in this pack

- [Volar](https://marketplace.visualstudio.com/items?itemName=vue.volar)
Language Support for Vue
- [SonarQube for IDE](https://marketplace.visualstudio.com/items?itemName=sonarsource.sonarlint)
Linter to detect & fix coding issues locally in JS/TS, etc
- [Vue VSCode Snippets](https://marketplace.visualstudio.com/items?itemName=sdras.vue-vscode-snippets)
Adds a useful snippet collection to improve your Vue workflow.
- [Vue Peek](https://marketplace.visualstudio.com/items?itemName=dariofuzinato.vue-peek)
Allows peek and goto definition for Vue single-file components.
- [Auto Rename Tag](https://marketplace.visualstudio.com/items/?itemName=formulahendry.auto-rename-tag)
Auto rename paired HTML/XML tag.
- [Bracket Highlighter](https://marketplace.visualstudio.com/items/?itemName=Durzn.brackethighlighter)
Decorates text inbetween symbols.
- [indent-rainbow](https://marketplace.visualstudio.com/items/?itemName=oderwat.indent-rainbow)
Makes indentation easier to read.
- [Path Intellisense](https://marketplace.visualstudio.com/items?itemName=christian-kohler.path-intellisense)
Visual Studio Code plugin that autocompletes filenames
- [Image preview](https://marketplace.visualstudio.com/items/?itemName=kisstkondoros.vscode-gutter-preview)
Shows image preview in the gutter and on hover.
- [CSS Peek](https://marketplace.visualstudio.com/items/?itemName=pranaygp.vscode-css-peek)
Allow peeking to css ID and class strings as definitions from html files to respective CSS. Allows peek and goto definition.
